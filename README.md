# RAGNAROK

An original, offline, stylized 3D arena-survival prototype made for Godot 4.7 .
It is a third-person survival shooter set in a low-poly arena. Fight off eight hostile bots, manage your health and ammo, and use the environment for cover. Build energy barricades, stay inside the arena walls, and survive for four minutes—or eliminate every enemy to win.

## Controls
| Input | Action |
| WASD | Move |
| Mouse | Aim / look |
| Left mouse | Fire |
| Space | Jump |
| R | Reload |
| Q | Place energy cover |
| Esc | Release mouse; click the game to recapture |
